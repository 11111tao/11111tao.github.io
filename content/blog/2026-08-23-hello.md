# 新站点，从 Material Design 3 到 Bear 风格

## 为什么要换

之前的 [11111tao.github.io](https://github.com/11111tao/11111tao.github.io)
是用 Vite + Material Design 3 搭的，写起来还行，但有俩问题：

1. **重**：MD3 的 web 组件拖了一堆 JS，
   打开 DevTools 一看首屏加载 1MB+。
2. **不好写**：每次想加一篇博客、记点东西，得去翻 React 代码、改组件、重新部署。
   写文章的摩擦太大了。

刚好前阵子刷到 [bearblog.dev](https://bearblog.dev)，
看到那句 *No javascript, no stylesheets, no trackers. Just your words.*
一秒心动。可惜它免费版限 10 篇。

去翻了翻它的源码和推荐方案，发现官方直接点名了一个 Hugo 主题：
[janraasch/hugo-bearblog](https://github.com/janraasch/hugo-bearblog)。
纯静态、零 JS、~5KB 每页、所有内容就是 markdown 文件——
基本上是我想要的 100% 复刻。

## 新栈

- **生成器**：[Hugo](https://gohugo.io/)（Go 写的那一个）
- **主题**：[hugo-bearblog](https://github.com/janraasch/hugo-bearblog)
- **托管**：GitHub Pages
- **部署**：推 `main` → GitHub Actions 自动 build → Pages

## 写文章的工作流

```bash
# 新建文章
hugo new blog/my-new-post.md

# 改完本地预览
hugo server -D

# 发布
git add . && git commit -m "post: my new post" && git push
```

完事，30 秒后线上更新。
